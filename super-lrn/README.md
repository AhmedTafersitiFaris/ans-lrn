# Super-LRN

A Super-LRN is a bundle of LRNs that each completed at least one full 365-day cycle of continuous monitoring, audit, testing, negative-evidence review, and revalidation under governance. Validated, active, popular, or profitable alone is insufficient. Offline continuity never bypasses governance. A future bundle must preserve source LRN, provenance, and audit references; this directory contains no operational LRNs.
