# Contributing

Use a pull request for every proposed LRN, validation event, audit, or governance change. Do not create a real LRN until its creator, independent validator, and independent auditor can participate in the review path.

1. Copy the LRN template to `lrns/proposed/`; never copy an example into an operational lifecycle directory.
2. Add positive and negative evidence, limitations, stop conditions, and a creator identity.
3. Run `powershell -ExecutionPolicy Bypass -File scripts/validate.ps1`.
4. Request an independent validator. Record conflicts and recusal.
5. Use the issue forms for a validation request or audit challenge; preserve links in the event record.

Do not claim an LRN is validated or active without the corresponding independent event. Do not delete adverse evidence; add a correction, audit, or retirement record instead.
